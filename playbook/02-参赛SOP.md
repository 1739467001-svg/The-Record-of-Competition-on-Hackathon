# 参赛 SOP · 从报名到路演

> 比赛不是从开赛那一刻开始的，是从**报名那一刻**开始的。
> 一个比喻：黑客松像一场**限时开卷考**。真正拉开差距的不是考场上写得多快，
> 而是**开考前你把哪几页答案抄进了参考书**。

---

## 阶段 0 · 报名（T-7 天或更早）

- [ ] 复用 [`sign-up-for-AI-Competitions`](https://github.com/1739467001-svg/sign-up-for-AI-Competitions) 里的个人信息，别重新填
- [ ] **抄下三个死线**：报名截止 / 作品提交截止 / 路演时间
- [ ] 确认参赛形式：线上 / 线下 / 混合，要不要到场
- [ ] 确认组队规则：人数上限、跨校能不能组、导师算不算人头
- [ ] **确认 IP 归属和奖金规则** —— 写在合同/章程里的那一条，不是主办方口头说的
- [ ] 建比赛记录文件 `competitions/YYYY-MM-DD-比赛简称.md`

---

## 阶段 1 · 定方向（T-3 天）

- [ ] 走完 [`01-选型决策法`](01-选型决策法.md) 的四关
- [ ] 把赛题信息、候选方向、评分卡、选定理由**全部填进比赛记录**
- [ ] **确认队友档期** —— 小智在不在决定视觉分，许恒在不在决定攻坚上限
- [ ] 一句话讲清项目：`____ 让 ____ 能够 ____，而现有方案做不到 ____。`
  > 这句话写不出来，就是方向还没想清楚。**别开工。**

---

## 阶段 2 · 赛前 48 小时（T-2 → T-0）

**这 48 小时决定 80% 的胜负。别用来写业务代码，用来铺路。**

- [ ] **先把部署链路打通** —— 建空仓库，推一个 Hello World 上 Vercel / Pages，确认能访问
  > 血泪经验：队里补部署这一环的人就是你。**最后半小时部署挂掉是最蠢的死法。**
- [ ] 从弹药库把要换皮的项目 clone 下来，**先跑通一遍**，确认不是坏的
- [ ] 准备**纯静态离线保底版**的骨架（断网也能演）
- [ ] 素材预备：主视觉方向、配色、字体、图标；能提前让小智出的先出
- [ ] 账号 / API Key / 额度确认（别到现场才发现额度用完了）
- [ ] 写好 README 骨架和路演稿骨架 —— **文档是提前写的，不是最后补的**

---

## 阶段 3 · 比赛日（以 36 小时赛制为例，按比例缩放）

| 时段 | 做什么 | 红线 |
|---|---|---|
| **0–6h** | 搭骨架：主场景 / 主流程能点通 | 6 小时还点不通 → **立刻砍功能** |
| **6–14h** | 填核心功能，只做能上台演的那条主线 | 不做设置页、不做登录、不做后台 |
| **14–20h** | 视觉打磨：动效、配色、转场、首屏 | 视觉分回报率最高的一段 |
| **20–26h** | **部署 + 跑通演示动线**，录一版备用视频 | **此时必须已经有能演的完整版本** |
| **26–32h** | 文档 / PPT / 路演稿 / 架构图 / 截图 | — |
| **32–36h** | 排练路演 ≥3 遍，掐表 | 超时是最常见的减分项 |

### 三条现场铁律

1. **演示动线只走一条。** 上台前把要点的每一下都排练死，别现场探索。
2. **随时保留一个能跑的版本。** 每完成一块就 commit + 部署，不要抱着一个半成品冲到最后。
3. **20 小时是分水岭。** 到点还没有能演的完整版本 → 停止加功能，转入收尾。

## 阶段 4 · 路演（3 分钟结构）

| 时长 | 内容 | 要点 |
|---|---|---|
| 0:00–0:20 | **痛点 + 一句话定位** | 从真实的人开口："我教的一个 12 岁学员……" |
| 0:20–1:40 | **现场演示** | 少说多演。第一个画面必须有冲击力 |
| 1:40–2:20 | **技术亮点 + 差异化** | 讲机制，不讲技术栈清单 |
| 2:20–2:50 | **落地 / 数据 / 下一步** | 有真实用户和数据就一定要说 |
| 2:50–3:00 | **团队 + 一句收尾** | 全链路身份那句话放这里 |

### 评委高频问题，提前准备答案

- "这跟 XX 有什么不一样？" → 差异化那句话，背熟
- "你这个到底省了多少钱 / 提了多少效率？" → **给数字**，哪怕是仿真数字（`aerotwin-tfu` 的 A/B 仿真就是为这句准备的）
- "谁会为它付钱？" → 说出具体的人：家长、学院、办赛方
- "比赛之后还做吗？" → 说清楚它怎么接进主线，别说"看情况"

## 阶段 5 · 赛后 48 小时（**最容易漏掉，但最值钱**）

- [ ] 回填 [`competitions/`](../competitions/) 里的结果与复盘
- [ ] **记下评委原话** —— 隔一周就忘了，那是最贵的反馈
- [ ] 新的可复用资产 → 回写 [`capability-map.md`](../profile/capability-map.md) 弹药库
- [ ] 结果 → 回写 [`track-record.md`](../profile/track-record.md)
- [ ] 判断有没有更新 → 回写 [`01-选型决策法.md`](01-选型决策法.md)
- [ ] 项目仓库补一份像样的 README（半年后你自己也需要它）
- [ ] 如果有署名 / 分成 / 后续合作没谈清楚 —— **现在谈，不要拖**

> **没复盘的比赛 = 没打。**
> 打了 18 场却记不清评委说过什么，那 18 场的价值只兑现了一半。
> 这个仓库存在的全部理由，就是把另一半兑现掉。
