# 选型决策法 · 拿到赛题后的 30 分钟

> ⚠️ **先走 [`00-信号分析法.md`](00-信号分析法.md)**，读懂主办方要什么、定好这场图什么，再回来选型。
> 信号没读就选型，等于闭着眼睛出牌。
>
> 这是整个仓库的核心。目标：**在 30 分钟内，从一个陌生赛题定出"最适合我"的方向。**
>
> 一个比喻：打比赛像打牌。别人是摸到什么牌打什么，你手上已经有一副**攒了半年的牌**（弹药库）。
> 所以你的动作不是"想一个点子"，而是 **"看这局能出我哪套牌"**。
> 这份文档就是出牌手册。

---

## 第一关 · 该不该打（拒绝条款）

**先过这一关。省下的时间比赢一场还值钱。**

命中任何一条，**直接不打**：

- ❌ 需要训模型、刷榜、拼精度 —— 没这个弹药，也没算力
- ❌ 需要硬件实物交付 —— 只有策划案，没有产线
- ❌ 必须上架原生 App —— 130 个仓库里没有一个原生项目
- ❌ 与手上**已开的战线**冲突 —— 同期只认真打一场（头号盲点：战线过多、全线漏鱼）
- ❌ 弹药复用率 < 30% **且** 奖励/资源不够高 —— 从零开始的成本要有人付
- ❌ 主办方要独占 IP 且不谈钱 —— 署名、归属、分成在开工前谈死（第三盲点：系统性低估价值）
- ❌ 赛题本质是"再做一个 ChatBot" —— 会撞 100 个同款，评委已经看吐了

> 🚩 **拒绝也是一次决策，也要记录。** 在 `competitions/` 建一条记录，写清"为什么不打"。
> 三个月后回看，你会发现拒绝对了什么、拒绝错了什么。

## 第二关 · 七维评分卡

三个候选方向各打一遍，**每维 1–5 分，满分 35**。

| # | 维度 | 问自己 | 5 分长什么样 |
|---|---|---|---|
| 1 | **弹药复用率** | 现成的能覆盖多少？ | ≥70% 踩在已有作品上，换皮即可 |
| 2 | **视觉冲击** | 路演前 30 秒评委会"哇"吗？ | 一开场就是跑得动的 3D 世界 |
| 3 | **现场稳定性** | 断网、评委电脑没环境，还能演吗？ | 纯静态零依赖，双击 index.html 就跑 |
| 4 | **故事真实性** | 有真人、真事、真数据背书吗？ | 我教过的学员 / 在线上跑的系统 / 我办过的赛 |
| 5 | **赛道差异化** | 会撞几个同款？ | 全场只有我这一个 |
| 6 | **团队适配** | 小智的设计、许恒的攻坚在不在？ | 三人齐、分工清楚 |
| 7 | **主 IP 复利** | 打完还能用第二次吗？ | 直接沉淀进青少年 AI 教育 / 数字员工主线 |

### 判定线

| 总分 | 结论 |
|---|---|
| **≥ 28** | 全力打，这是你的主场 |
| **22–27** | 可以打，但要针对低分维度补救（见下方补救表） |
| **18–21** | 除非奖励极高或有战略价值，否则放掉 |
| **< 18** | 不打 |

### 低分维度补救表

| 哪一维低 | 怎么救 |
|---|---|
| 弹药复用率低 | 换一个方向，别硬做 —— 这是唯一不建议硬补的一维 |
| 视觉冲击低 | 加一个 3D 场景或 Framer Motion 动效层；把小智拉进来 |
| 现场稳定性低 | 提前做一个**纯静态离线版**当保底演示（这是你的看家本领） |
| 故事真实性低 | 找一个真实用户（学员 / 家长 / 老师）录 30 秒视频，比任何 PPT 都硬 |
| 赛道差异化低 | 别做"通用版"，往你独有的场景里钻（校园 / 青少年 / 赛事现场） |
| 团队适配低 | 砍功能，别砍质量。一个人就做单点极致的那一个 |
| 主 IP 复利低 | 想清楚这场是"换钱"还是"换名"，换完就走，别恋战 |

## 第三关 · 四套默认打法

**九成赛题能对号入座。** 先分类，再往弹药库里取货。

### 🏗️ A 打法 · 孪生流

**适用赛题**：产业智变 / 智慧城市 / 交通 / 能源 / 制造 / 物流 / 双碳 / 应急

**招式**：`3D 数字孪生场景` + `多智能体数字员工班组` + `调度算法 A/B 影子仿真`

**取货**：`cargo-claw`（港口）、`Smart-Port`（5 名数字员工班组叙事）、`aerotwin-tfu`（A/B 仿真）、
`deepblue-rig`（电影级渲染）、`bawei`（气象）、`SmartContainer-3D`（单体设备）

**为什么赢**：别人三天只能做出网页表单 + API 调用，你直接开出一个跑得动的 3D 世界。
再叠上"每个数字员工对应一个真实岗位、可观察、可下钻、可替代"这套叙事 —— 技术分和创意分同时拿。

**杀手锏**：`aerotwin-tfu` 那套 **A/B 影子仿真**（同一场景跑两套调度算法对比）。
它把"好看"变成"有效"，直接回答评委最爱问的那句 **"所以你这个到底省了多少钱？"**

---

### 🎓 B 打法 · 教育流

**适用赛题**：教育 / 公益 / 普惠 / 青少年 / 心理健康 / 乡村振兴 / 银发

**招式**：`真实学员` + `真实跑过的课` + `可量化的评估量表`

**取货**：`Teenager-Guide`（《上瘾自律》完整课程 + 弹性尺量表）、`VR-Class`（AI 现场生成一堂课）、
`Fishing`（儿童小游戏）、`IST` / `ImageProcessing`（学习站脚手架）、`AI-Enlightenment-1`

**为什么赢**：**这一层别人伪造不了。** 教育赛道最大的通病是"我觉得孩子需要" ——
全场都在讲设想，只有你能说"我教了一年多，这是 4 个孩子前后测的真实数据"。

**杀手锏**：**「弹性尺」量表**。它天然产出"双人独立评分 + 前后测"的规范结构。
教育赛题的评委最缺的就是**量化证据**，你手上恰好有一把尺。

> ⚠️ **护栏**：涉及未成年人，一律用代称，绝不放真实姓名 / 学校 / 正脸照片。
> 下次开课前先把**家长数据使用同意书**签掉 —— 上一次白白流掉了一批好数据，别再浪费第二次。

---

### 🎪 C 打法 · 赛事流

**适用赛题**：效率工具 / 组织协作 / 社区 / 活动 / Agent 应用 / 开发者生态

**招式**：`赛事与活动基础设施` —— 抽奖、报名、志愿者调度、作品展示、评审流程、现场大屏

**取货**：`lottery-system`×4、`zjsu-ai-hackathon` / `funskills-starlight`（星河长廊）、
`ai-hackathon-showcase`、`hackathon-poster`、`Aesthetic-Design-by-Doubao`（主视觉批量生成）、
`sign-up-for-AI-Competitions`

**为什么赢**：**全场只有你一个人真的办过赛。** 别人在猜用户的痛点，你就是那个用户。
当你说"志愿者排班最大的坑是签到和补位"，评委里只要有一个办过活动的，当场就信了。

**杀手锏**：走完全链路的身份本身 —— `选手 → 志愿者 → 工作人员 → 协办 → 主办`。
这句话在路演里说出来，比任何技术参数都有说服力。

---

### 🦞 D 打法 · Skill 流

**适用赛题**：各平台的 Skill / Agent / 插件创新赛（商汤、讯飞、腾讯云、百度千帆、繁星计划……）

**招式**：**单点极致的一只"虾"** —— 不做大而全，做一个小而深、有独特机制的 Agent

**取货**：`meeting-room-shrimp`（**现成的比赛提交包结构，照抄**）、`soulvoice`（二等奖）、
`c-tongji`（多 Agent 协同）、`Astudio_langchain-langgraph`（技术深度背书）

**为什么赢**：这类赛事评的是**机制的巧思**，不是工程量。
SoulVoice 拿二等奖靠的就是一句话讲清的机制：
**"别的陪伴 AI 今天和一年后听起来一样，我的声音会随关系亲密度渐变。"**

**杀手锏**：一句话能讲清、且别人没想到的机制。定方向时先写这句话，写不出来就换方向。

> ⚠️ **别复刻别人的爆款。** 复刻 = 永远第二名。
> 你的长板是讲台、信用、组织力、真实场景 —— 走自己的线。

## 第四关 · 快问三句（定方向前最后一道闸）

1. **这题的真实用户我认识吗？** 认识 → 优先。你手上有学员、家长、老师、办赛人、企业 HR。
2. **我能不能在 6 小时内做出可点击的样子？** 不能 → 砍到能为止。
3. **打完之后，这东西还能用第二次吗？** 不能 → 想清楚你是来换钱还是换名，换完就走。

## 这份文档怎么长大

每打完一场，回来问三件事：
1. **评分卡有没有算错？** 哪一维的分虚高了 / 低估了？
2. **有没有出现第五种打法？** 有就加上。
3. **拒绝条款要不要加一条？** 踩到新坑就补一条进去。

> 判定线和权重**不是拍脑袋定死的**，是要被真实战绩校准的。
> 打满 5 场后回头改一次分数线 —— 那时的数字才有意义。
